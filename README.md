# 艾森豪威尔四象限待办事项管理系统

这是一个基于React和Vite构建的待办事项管理应用，采用艾森豪威尔四象限法则（Eisenhower Matrix）对任务进行分类和优先级排序。该应用帮助用户根据任务的紧急程度和重要程度进行有效的时间管理和任务规划。

![艾森豪威尔四象限](public/页面演示.svg)

## 功能特点

### 四象限任务分类
- **第一象限(Q1)**: 紧急且重要的任务，需要立即处理
- **第二象限(Q2)**: 重要但不紧急的任务，需要计划执行
- **第三象限(Q3)**: 紧急但不重要的任务，可考虑授权他人
- **第四象限(Q4)**: 不紧急不重要的任务，尽量避免或减少

### 任务管理功能
- 添加新任务，并设置任务的重要性和紧急性
- 标记任务为已完成/未完成
- 编辑现有任务（双击任务文本）
- 删除单个任务
- 清除所有已完成的任务

### 任务筛选与排序
- 查看全部任务、仅活跃任务或仅已完成任务
- 自动根据四象限法则对任务进行优先级排序
- 未完成的任务始终显示在已完成任务之前

### 数据持久化
- 使用浏览器的localStorage自动保存任务数据
- 页面刷新后仍保留任务状态

## 使用指南

1. **添加任务**：在顶部输入框中输入任务内容，选择任务的重要性和紧急性，然后点击添加按钮或按回车键
2. **编辑任务**：双击任务文本进行编辑，按回车键保存，按Esc键取消
3. **完成任务**：点击任务前的复选框标记任务为已完成
4. **删除任务**：点击任务右侧的删除图标删除单个任务
5. **筛选任务**：使用底部的"全部"、"进行中"、"已完成"按钮筛选任务
6. **清除已完成**：点击底部的"清除已完成"按钮删除所有已完成的任务
7. **调整优先级**：点击任务右侧的"重要"和"紧急"按钮调整任务的优先级

## 技术栈

- **React**: 用于构建用户界面的JavaScript库
- **Vite**: 现代前端构建工具
- **Tailwind CSS**: 用于样式设计的实用工具优先的CSS框架
- **localStorage API**: 用于本地数据持久化
- **useReducer Hook**: 用于复杂状态管理

## 开发者说明

- 使用React的useReducer和useState钩子进行状态管理
- 采用组件化设计，每个功能模块独立封装
- 使用localStorage实现数据持久化
- 响应式设计，适配不同屏幕尺寸
